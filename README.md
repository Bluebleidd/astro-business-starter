## About
A high-performance, minimalist Astro template tailored for local service businesses. It utilizes a zero-JS architecture by default and completely separates data from UI using JSON files. Designed for maximum speed, scalability, and easy maintenance.

## Features
* **Integrated Headless CMS:** Built-in `/admin` panel (Static CMS) that commits changes directly to GitHub API.
* **Data-Driven UI:** All business data (pricing, services, contact) is decoupled and managed via JSON files.
* **Custom Vanilla JS Slider:** Lightweight, interactive "Before & After" image comparison without external libraries.
* **Mobile-First & Responsive:** Clean, vanilla CSS architecture adapted for all devices.
* **SEO Optimized:** Fast loading times and fully dynamic meta tags.

## Tech Stack
* **Framework:** Astro (Island Architecture)
* **Logic:** JavaScript / TypeScript
* **Styling:** Vanilla CSS
* **CMS / Storage:** Static CMS / JSON
* **Icons:** Lucide-Astro
